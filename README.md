# The Accumulating-Context Agent

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22087441.svg)](https://doi.org/10.5281/zenodo.22087441)
[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

The unit of value in agent systems is not the model call — it is the **accumulated context**. An identity
that has read its own ledgers for months can draw on decisions and corrections a fresh prompt would have to
reconstruct from scratch. **Engines rent intelligence; the accumulation is owned.** This is why identity
lives on disk, why memory is bi-temporal, why ledgers must not lie, and why context-hygiene is treated as
an engineering discipline — with brakes, anchors, and pickup chains.
